# «С рук» — первые 3D-прототипы

Три модели для согласования внешнего вида. Это прототипы ассетов, не готовая игра.

- `smartphone.glb` — вымышленный смартфон с интерфейсом «Барахло». Отдельные объекты корпуса, экрана, аккумулятора, кнопок и камер.
- `repair_workbench.glb` — ремонтный стол, ящики, коврик, инструменты, лампа и блок питания.
- `starter_room.glb` — комната с кроватью, кухонным уголком, окном и полкой. Стол и телефон поставляются отдельно для свободной расстановки.
- `s_ruk_prototypes.blend` — общий редактируемый исходник и сцены превью.
- `01_smartphone.png`, `02_workbench.png`, `03_room.png` — рендеры моделей.

## Использование

GLB импортируется в Godot 4; Blender открывает GLB и исходный .blend. Размеры в метрах. Blender: Z вверх; glTF экспортируется со стандартным Y вверх. Материалы процедурные, внешние текстуры не нужны. Коллекция `Presentation_only` содержит свет, камеру и фон только для рендера.

Пример расстановки в комнате в координатах Blender: стол `(0.30, 1.23, 0)`, смартфон `(0.10, 1.20, 0.82)`.

Это проверка художественного направления: скруглённые формы, приглушённая бирюза, тёплое дерево, оранжевые акценты. Не выполнены финальная оптимизация для мобильных устройств, коллизии, анимации ремонта, интерактивность и проверка на устройстве. Надписи на экране пока геометрические; в игре их стоит заменить динамическим интерфейсом/текстурой. Аккумулятор показан внутри корпуса условно; внутренние компоненты требуют дальнейшей детализации.

## Пересоздание

Из `/workspace/game`:

```sh
blender -b -t 4 --python tools/build_prototypes.py
```

Проверено в Blender 4.3.2. Для надписей нужен `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`. Скрипт создаёт новую сцену; запускайте его в фоновом Blender, а не поверх несохранённой работы.
