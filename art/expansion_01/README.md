# «С рук» — магазины, ремонт и Azon

Первый набор для согласования визуального стиля и проверки игрового заказа деталей. Старые модели комнаты, стола и смартфона сохранены в соседних каталогах.

## 3D-модели

| Файл | Содержимое |
| --- | --- |
| `grocery_pyatak.glb` | Магазин «Пятак»: фасад, окна, дверь, полки с товарами, касса, фрукты. |
| `azon_pickup.glb` | Синий пункт выдачи Azon: отдельный вход, стойка, терминал, стеллажи и посылки. |
| `repair_tools.glb` | Общий набор инструментов, магнитный коврик, восемь винтов. |
| `precision_screwdriver.glb` | Прецизионная отвёртка. |
| `tweezers.glb` | Пинцет. |
| `nylon_spudger.glb` | Пластиковая лопатка. |
| `opening_pick.glb` | Медиатор для вскрытия. |
| `suction_cup.glb` | Присоска с ручкой. |
| `micro_screw.glb` | Отдельный микровинт с крестовым шлицем и условной резьбой. |
| `usb_c_charger.glb` | Блок питания 20 Вт с европейской вилкой и кабель USB-C. |
| `repairable_phone_exploded.glb` | Телефон в разобранном виде: корпус, задняя крышка, дисплей, аккумулятор, платы, камеры, межплатный шлейф, два шлейфа дисплея, разъёмы и восемь винтов. |
| `expansion_01.blend` | Общий исходник Blender с редактируемыми объектами, камерой, светом и расстановкой магазинов. |

Размеры в метрах, модель телефона примерно 75 × 157 мм. GLB использует стандартную ось glTF Y вверх. Отдельные инструменты центрированы по XY, низ на Z=0 в Blender. У зданий есть простые интерьеры; крыша отдельным объектом. Ремонтные узлы и ленты шлейфов — условная игровая модель, не техническая копия настоящего смартфона. Винты сгруппированы по имени; части телефона названы отдельно.

Для примера расстановки в Blender: магазин `(-1.78, 0, 0)`, пункт `(2.14, 0, 0)`. Общая коллекция `Street_presentation` содержит копии моделей, тротуар и дорожку только для демонстрации. `Presentation_only` содержит фон, свет и камеру. Коллекции исходных моделей скрыты в сохранённом viewport, чтобы не накладываться на демонстрационные копии; их можно включить в Outliner.

## Приложение Azon

- `phone_demo.html` — самостоятельный кликабельный прототип телефона. Откройте файл в браузере. Внешние библиотеки и Интернет не нужны. Если браузер запрещает локальные HTML-файлы, обслуживайте каталог обычным локальным HTTP-сервером.
- `azon_screen.png` — статический макет каталога, встроенный в экран разобранного телефона.
- `phone_home.png` — отдельный макет домашнего экрана с иконками приложений.
- `05_azon_demo.png` — снимок работающего HTML-прототипа.

В демонстрации работают корзина, ограниченное количество товара, оплата игровыми деньгами, доставка через 1–3 игровых дня, одноразовое получение заказа и инвентарь. Кнопка «Сон» снаружи телефона двигает время для проверки. Партия приходит целиком по сроку самой долгой позиции. Состояние сохраняется в localStorage при доступности браузерного хранилища. «Начать заново» сбрасывает демонстрацию. Никаких настоящих заказов, аккаунтов и платежей нет.

В каталоге намеренно нет всего: дисплей R / 01 недоступен, микросхемы вообще не представлены. «Авиту» в демонстрации показывает объявление донора; покупка донора, настоящая локация получения и использование запчастей пока не подключены. Пополнение остатков не реализовано.

## Проверено

Все GLB повторно импортированы в Blender 4.3.2. В Chromium проверены ограничение количества, недоступный товар, списание средств, доставка за один и три дня, запрет раннего/повторного получения, инвентарь, сохранение после перезагрузки, поиск отсутствующей детали и ширина интерфейса на мобильном viewport.

Это прототипы ассетов и отдельная HTML-демонстрация. Не выполнены интеграция с игровым движком, анимации разборки, коллизии, навигация внутри магазинов, финальная оптимизация для Android и сборка APK/Windows. Двери пока не анимированы, петли и точки взаимодействия требуют настройки в движке.

«Пятак» и Azon — рабочие вымышленные названия с собственными знаками и оформлением. Близкое написание не гарантирует отсутствия претензий; юридическая проверка перед релизом не выполнена.

## Пересоздание

Из `/workspace/game`:

```sh
python3 tools/draw_azon_ui.py
blender -b -t 4 --python tools/build_expansion_01.py
blender -b -t 2 --python tools/export_repair_modules.py
```

Нужны Python с Pillow, Blender 4.3.2 и DejaVu Sans. Вспомогательные функции берутся из `tools/build_prototypes.py`, входящего в архив. Исходники предыдущих моделей не перезаписываются. Скрипты запускать фоновым Blender, чтобы не затереть несохранённую сцену.
