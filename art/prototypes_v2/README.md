# Смартфон v2 / «Авиту»

Новый вариант для согласования внешнего вида. Предыдущие три модели сохранены в `../prototypes`.

- `smartphone_v2.png` — рендер обновлённого смартфона.
- `avitu_screen.png` — оригинальный макет интерфейса 780 × 1600, также встроен в GLB и .blend.
- `smartphone_v2.glb` — отдельная модель с материалами и встроенной текстурой.
- `smartphone_v2.blend` — редактируемый исходник с камерой и освещением.

Размер корпуса: 75 × 157 × 9 мм (камеры и кнопки выступают). Материалы: тёмно-синий корпус и сатинированная металлическая рамка. Экран имеет UV-развёртку; надписи больше не являются выступающей геометрией. Отдельные объекты кнопок, разъёма, камер и дисплея. Это внешний прототип без моделирования внутренних узлов ремонта.

Интерфейс — статический макет, кнопки пока не работают. В игровой версии UI нужно подключить как динамический интерфейс. Все объявления и рейтинги вымышлены. Продуктовые миниатюры нарисованы программно специально для макета. Название «Авиту» — рабочее по пожеланию пользователя; проверка прав на название и юридическая оценка не выполнены. Отличающееся написание и оформление не гарантируют отсутствия претензий.

## Пересоздание

В `/workspace/game`:

```sh
python3 tools/draw_avitu_ui.py
blender -b -t 4 --python tools/build_phone_v2.py
```

Проверено: Python с Pillow, Blender 4.3.2, шрифт DejaVu Sans. Второй скрипт использует материалы и вспомогательные функции из `tools/build_prototypes.py`. Файлы предыдущей версии не перезаписываются.
