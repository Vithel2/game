# Черновик карточки RuStore

Название: Перекуп: второй шанс
Разработчик: Vithel
Контакт: vithelusa@gmail.com
Категория: симуляторы
Короткое описание: Покупай технику с рук, ремонтируй и строй своё дело в живом районе.

Из чужого хлама — в своё дело. Начни с маленькой мастерской: осматривай объявления, договаривайся о встречах, меняй детали и продавай восстановленные устройства. Заказывай запчасти, помогай соседям, находи старую технику в сквере и обустраивай дом. Снимай игровые ролики для YouTech и наблюдай за постепенным ростом аудитории.

Версия 0.12: YouTech, исправленный порядок движения дисплея при ремонте, плавные окна, разнообразные ежедневные сделки и задания, новый вход в сквер, компактный мобильный интерфейс, портретный режим, перенос сохранений и закрытые глаза во сне.

Интернет во время игры не требуется. Требования: Android 8.0+, актуальный Android System WebView с WebGL 2. Управление — касаниями. Игра не содержит реальной торговли, сетевого рейтинга или денежных выплат.

## Перед отправкой на модерацию

Нужен release APK с постоянной подписью. Debug APK предназначен только для тестирования. Предварительно экспортируйте прогресс: приложения с разными подписями не обновляют друг друга.

Ключ и пароли должны храниться в GitHub Actions Secrets, а также в двух приватных резервных копиях. Не помещать их в публичный архив. Новый ключ создан в этой сессии; подпись release через Actions пока не выполнена из-за блокировки GitHub API.

Политика: privacy-policy.md — разместить по постоянному публичному HTTPS-адресу. Скриншоты в mobile/ сняты с реальной игры в 1080×1920, PC-кадры отдельно в pc/. Иконка — icon-512.png. Трейлер — trailer-1080p60.mp4.

Актуальные требования RuStore не подтверждены: сайт блокируется сетевой политикой среды. Перед загрузкой проверить форматы медиа, требования к SDK/подписи и возрастной маркировке. Права на ранее предоставленные музыкальные треки в самой игре ещё необходимо подтвердить. Производительность на физическом Android-устройстве не измерялась. Комплект не заявлен готовым к модерации.
