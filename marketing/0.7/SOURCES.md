# Источники материалов

Иконка сгенерирована для проекта с помощью инструмента генерации изображений OpenAI. Исходник сохранён в icon-master.png, экспорт для магазина — icon-512.png.

Скриншоты сняты непосредственно в игровой сборке. Для показа обустроенного дома и ремонта использованы подготовленные состояния с открытым прогрессом. Мобильные PNG: 1080 × 1920; ПК: 1280 × 720.

Трейлер: 25,5 секунды, H.264/AAC, 1280 × 720. Четыре записи реальной 3D-сцены, подписи и финальная карточка. Исходная запись — 12 кадров/с в программном Chromium; экспорт — 24 кадра/с. Это не замер производительности на устройстве. Музыка: HoliznaCC0 — MIdLife из пользовательского архива. Игровые звуки записаны из Web Audio: эффекты Kenney CC0. Музыка сведена поверх игровых звуков. Сведения о правах — licenses/SOURCES.md.

Скрипты воспроизведения процесса: tools/capture_marketing.mjs и tools/make_trailer.py в репозитории. Сырые временные записи хранятся только во временной рабочей папке, не включены в комплект.
