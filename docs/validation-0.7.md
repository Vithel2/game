# Версия 0.7 — основные проверки

По запросу приоритет отдан основным сценариям; полный набор длительных регрессий этой версии не повторялся.

Пройдено:

- Четыре активные цели; покупка ковра и улучшение стартовой комнаты.
- Сыр: выбор на полке, перенос в корзину, оплата и появление в запасах.
- Выбор смены в Пятаке; работа остаётся в Пятаке.
- Azon: первая задача с кодом 013, поиск коробки, перенос и передача сотруднику, переход к следующей задаче.
- Шансы помощи 0% дома без друзей, 30% дома с друзьями, 80% на улице. Сохранение исхода падения, больница и восстановление. Браузерный сценарий проверен с фиксированным случайным числом для ветки спасения.
- Покупки мебели, запрет повторной покупки и двойной выплаты, повышение уровня жилья, перенос сохранения схемы 7 в 8.
- Проверены перенос экрана без дублирования, точная модель запчасти, вращение отвёртки и движение кисти по траектории, контакт наконечника с винтом (`tests/repair6.e2e.mjs`).
- Сохранились проверки прежней миграции, обучения, сюжетных условий, уровней ремонта и монетизации.
- Записан трейлер из четырёх игровых сцен; MP4 H.264/AAC, 1280 × 720, 25,52 секунды. В записанном звуковом канале есть игровые эффекты; поверх сведена музыка.
- Подготовлены три мобильных PNG 1080 × 1920, три ПК-кадра 1280 × 720, непрозрачная PNG-иконка 512 × 512 и описание карточки.

Команды: `npm run test:release7`, `npm run test:release7-browser`, `npm run test:survival`, `npm run test:state`, `npm run test:life`, `npm run test:progression`. Браузер — Chromium с программным WebGL. Проверка автономного HTML: `npm run test:offline`, без внешних запросов.

Отдельные APK и Windows-приложение не собраны, в RuStore ничего не опубликовано. Материалы предназначены для подготовки карточки. Частота кадров трейлера не характеризует производительность на реальном телефоне. Источники и ограничения аудио включены в комплект материалов. Предметы дома ставятся в подготовленные места; свободного редактора расстановки пока нет.
