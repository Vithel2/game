# Проверки версии 0.9

Изменения: внутренние винты после вскрытия/отключения дисплея, 3–7 винтов, экран лежит на коврике до сборки, обход дисплея инструментом через подъём; большой Azon с коробками только во время смены и раздельными анимациями; следующий код без повторного открытия подработки; расширенный дом мастера и новый внешний этаж; постепенный уход прохожих; Windows-установщик, APK и новые видео.

## Выполнено

- `npm run test:release9`: весь порядок ремонта всех четырёх сложностей, максимум семь винтов, старые маски 10/12 винтов не перезапускают ремонт; расписание жителей и видимый уход с плавным исчезновением у края улицы.
- `npm run test:progression`, `test:state`, `test:release8`: сезоны, сюжет, подработки, сохранения, новые/старые названия и диагностика.
- Целевой браузерный сценарий дома и ремонта: покупка дома мастера, видимая новая комната и второй этаж, вскрытие до винтов, пять внутренних винтов, горизонтальный дисплей, полная разборка/сборка и итоговая проверка телефона. Склад проверен отдельным полным сценарием ниже.
- `tests/parcel9.e2e.mjs`: до смены кодированные коробки скрыты; все пять посылок найдены, взяты с полки и переданы Маше; следующий код появляется автоматически; в конце выдана зарплата и коробки снова скрыты. Ошибок JavaScript нет.

## Дистрибутивы

- APK успешно собран через Cordova/JDK 17/SDK 35/Gradle 8.13. `apksigner verify` подтвердил подпись APK v2, `aapt` — com.vithel.perekup, versionCode 900, versionName 0.9.0, min SDK 26, target SDK 35.
- Windows-приложение скомпилировано как x64 GUI .NET EXE, с иконкой, манифестом asInvoker и версией 0.9.0.0. NSIS создал настоящий установщик; отдельно подготовлен портативный ZIP.
- ZIP-структуры проверены. HTML в APK и Windows-версии побайтно совпадает с браузерным офлайн-архивом (в APK дополнительно подключается локальный Cordova bridge). Модели, шрифты и музыка встроены; ключей подписи внутри пакетов нет.
- На физических Android/Windows устройствах запуск не проверен. Windows использует уже установленный Edge WebView2; установщик без коммерческой цифровой подписи. APK с тестовой подписью, для RuStore нужен постоянный ключ разработчика.

## Видео

Кадры нового трейлера рендерятся из реальной симуляции с шагом 1/60 секунды в 1920×1080. Это не увеличение старого ролика 12 fps. Обучение записано с интерфейсом в 1600×900/30 fps; повторяющиеся винты и длинные переходы сокращены монтажом. Музыка и игровые эффекты смешиваются отдельно, эффекты привязаны ко времени действий в симуляции. FPS экспорта не является измерением производительности игры на телефоне.

Сведения о числе кадров, разрешении и звуковых событиях сохраняются в `marketing/0.9/*-capture.json`; результат фактического прохождения обучения — `tutorial-result.json`.
