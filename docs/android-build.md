# Android APK

Игра упаковывается через Cordova, по тому же принципу, что и Vithel2/arseniy-god. Все модели, музыка, шрифты и код встроены локально; игровой интернет не нужен. Портретная и альбомная ориентации поддерживаются.

## Локальная сборка

Нужны Node.js 22, JDK 17, Android SDK platform 35/build-tools 35.0.0, Gradle 8.13. Установите `ANDROID_HOME`, `JAVA_HOME`, добавьте Gradle в PATH.

```sh
npm ci
npm run prepare:android
cd android-app
npm ci
npx cordova platform add android@14.0.1 --no-telemetry
npx cordova build android --debug --no-telemetry -- --packageType=apk
```

Результат: `android-app/platforms/android/app/build/outputs/apk/debug/app-debug.apk`.

Требования: Android 8.0+, актуальный Android System WebView с WebGL 2. На настоящем телефоне производительность этой версии пока не проверена. Прогресс браузера автоматически в Android-приложение не переносится. Android-приложение хранит свой прогресс локально. Системная кнопка «Назад» закрывает окно или открывает паузу; при сворачивании прогресс сохраняется, звук приостанавливается.

## GitHub Actions

Workflow `.github/workflows/build-apk.yml` автоматически создаёт тестовый APK при изменениях игры в main; также доступна кнопка Run workflow. Открой Actions → Build Android APK → успешный запуск → Artifacts → Perekup-0.11-test-APK. Артефакты GitHub обычно требуют входа в аккаунт.

`releases/perekup-0.11-debug.apk` — отдельно собранный устанавливаемый тестовый APK. Он подписан отладочным ключом, не предназначен для публикации в RuStore. Локальная сборка и GitHub Actions могут использовать разные отладочные ключи; между ними может понадобиться переустановка с потерей локального сохранения. Не удаляйте текущую установку, если её прогресс важен.

## Постоянная подпись для магазина

В GitHub Settings → Secrets and variables → Actions нужны `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` — постоянный приватный ключ разработчика и его параметры. При наличии секретов workflow дополнительно соберёт `Perekup-0.11-store-APK`. Ключи не генерируются автоматически, не попадают в репозиторий или публичные артефакты. Не меняйте ключ между обновлениями приложения.

Перед публикацией остаются проверка на реальных Android-устройствах, подпись ключом разработчика, проверка прав на музыку и оформление карточки в RuStore.

## Облачная среда

Gradle/Java должны использовать штатный прокси среды и доверенное системное хранилище CA. Настройки прокси и пути из временной облачной машины не записаны в проект или GitHub workflow. Для локальной проверки использовались временные SDK/JDK/Gradle в `/tmp`, они не нужны пользователю при скачивании готового APK.
