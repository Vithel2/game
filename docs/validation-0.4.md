# Проверка версии 0.4

Проверено 28 октября 2026 года в Chromium на Linux с программным WebGL. Десктопные сценарии выполнялись мышью и клавиатурой; мобильные — касаниями при 390 × 844. Состояние игры доступно тестам только для чтения. Фикстуры используются для отдельных проверок позднего прогресса.

| Проверка | Результат |
| --- | --- |
| `npm run build` | Сборка без CDN, модели и аудио встроены |
| `npm run test:state` | Перенос старого сохранения и восстановление после повреждённого JSON |
| `npm run test:life` | Обязательное обучение, продолжение, ограничения публикации, доход и рост соперников |
| `npm run test:navigation` | Маршруты четырёх локаций; столкновения с кроватью, столом, скамейкой и кассой |
| `npm run test:e2e` | Вся первая сделка и обучение: покупка, инструменты, ремонт, сон, заказ, выдача, сборка, продажа, сохранение |
| `npm run test:rework` | Модели каталога, высота телефона, корзина на 14 товаров, касса, еда, выходы, друзья, контраст ПК, Youpube, реклама, рейтинг и сохранение |
| `npm run test:expansion` | Клиентский ремонт и премия без повторной выплаты, покупка и улучшения ПК, обе мини-игры, задания, звук и выключение звука |
| `npm run test:mobile` | Создание героини и выбор способности, обучение, питьё, корзина на 8 товаров, касса и управление мини-играми касаниями |
| `npm run test:gadgets` | Покупка и полный ремонт геймпада с четырьмя винтами, контакт отвёртки с винтом, физическая деталь на столе, продажа; модели колонки и наушников |
| `npm run test:resume` | Продолжение незаконченного обучения, повторное назначение потерянной встречи, сохранение встречи и её завершение |
| `npm run test:offline` | Архив распакован отдельно; одиночный HTML запускается через локальный сервер, внешних запросов нет |

Все перечисленные проверки завершились успешно. Во время прохождения автоматические проверки не обнаружили ошибок JavaScript.

`file://` заблокирован политикой браузера облачной среды, поэтому автономный файл проверен через изолированный локальный сервер. Производительность на реальном Android и отдельные APK/Windows-сборки не проверялись. Соперники Youpube управляются игрой; сетевого рейтинга нет.
