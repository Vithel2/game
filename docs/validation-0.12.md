# Проверки версии 0.12

Дата: 29 октября 2026 года. Проверка выполнена в Linux, Node.js 24.19.0, системный Chromium 154 с программным WebGL. Реальный Android и запуск Windows EXE на Windows не проверялись.

## Прошло

- `npm run build` — автономный bundle.
- `test:state`, `test:life`, `test:navigation`, `test:progression`, `test:trading`, `test:release8`, `test:release11` — миграции, игровой цикл, препятствия, уровни ремонта, торговля, постепенная аудитория и её сохранение.
- `test:release12` — закрытые веки/обычное моргание обоих аватаров; детерминированные предложения после покупки другого товара; смена предложений и заданий по дням; импорт, резервная копия и отбрасывание повреждённого JSON.
- `tests/release12.e2e.mjs` — сон с закрытыми глазами и пробуждение, каталог деталей без ОС, перенос прогресса с перезагрузкой, повреждённый импорт без потери прогресса, пауза в альбомном режиме, ввод с клавиатурой, маршрут и возврат из перенесённого сквера.
- `tests/repair12.e2e.mjs` — полный мобильный ремонт: поднять → отключить → отложить → заменить → закрепить → вернуть → подключить → закрыть → проверить. Запасной дисплей без копии диагностики, руки не создаются, основные кнопки не меньше 44 px.
- `tests/dialog12.e2e.mjs` — после заказа деталей остаётся тот же диалог и прокрутка, анимация открытия не повторяется; закрытие создаёт неактивный переход и удаляет его.
- `test:release11-browser` — анимация календаря, магазин и установка оплаченных комплектующих, постепенный рост просмотров на реальном UI, счётчики без пересоздания окна, сохранение, полные мобильные интерьеры и плавные уличные подписи.
- `test:offline` — запуск единственного HTML с моделями, шрифтами и аудио без внешних запросов.
- Debug APK собран Cordova Android 14.0.1, SDK/build-tools 35, JDK 17, Gradle 8.13. `aapt`: пакет com.vithel.perekup, versionName 0.12.0, versionCode 1200, min SDK 26, target SDK 35, screenOrientation portrait. `apksigner verify` прошёл; сертификат Android Debug.
- Windows EXE скомпилирован Mono, NSIS-установщик и portable ZIP собраны; заголовки PE и ZIP проверены скриптом сборки. Для запуска нужны Windows и WebView2.
- Экспортированные мобильные PNG — 1080×1920, PC PNG — 1920×1080.

Сборка и тесты меняли только предназначенные для этого generated-файлы; код схемы сохранения остаётся версии 8. Старые релизы сохранены.

## Ограничения публикации

Постоянный ключ создан вне репозитория. Резервная копия приватная и не входит в публичный комплект. Release APK через GitHub Actions Secrets не собран: GitHub API заблокирован сетевой политикой; пользователь должен добавить четыре секрета по приватной инструкции. Публичный комплект содержит debug APK для тестирования.

Сайт RuStore также заблокирован, поэтому актуальные требования модерации не подтверждены. Политика и карточка — подготовленные тексты, требующие проверки перед отправкой. Контакт: vithelusa@gmail.com. Права на старые пользовательские музыкальные треки внутри игры требуют подтверждения; для нового трейлера создана отдельная процедурная музыка. Тесты на физических телефонах и проверка установки Windows не выполнены. Эти ограничения не следует считать пройденными проверками.

Рендер трейлера использует настоящую симуляцию по 1/60 секунды на кадр. Для экономии программного WebGL карты теней обновляются 6 раз в секунду; геометрия и выходное видео — 60 кадров/с. Обычная игра этим режимом не затрагивается.

Трейлер проверен ffprobe: H.264, 1920×1080, 60/1 fps, 1926 кадров, длительность 32,1 с, стереозвук AAC. Восемь игровых сцен содержат 1746 кадров симуляции и 57 звуковых событий, финальная заставка — 180 кадров.
