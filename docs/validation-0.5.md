# Проверка версии 0.5

28 октября 2026 года. Chromium на Linux, WebGL через SwiftShader. Десктопные сценарии выполнялись мышью и клавиатурой, мобильные — касаниями при 390 × 844. Для позднего прогресса используются фикстуры сохранений. Игровое состояние в браузерных тестах доступно только для чтения.

| Проверка | Подтверждено |
| --- | --- |
| `npm run build` | Самостоятельная сборка с GLB и аудио, без runtime CDN |
| `npm run test:state` | Перенос старых денег и ремонтов в схему 6, восстановление после повреждённого JSON |
| `npm run test:life` | Обязательное обучение, продолжение, ограничения влогов, доход, способности и соперники |
| `npm run test:navigation` | Маршруты основных локаций; столкновения со столом, кроватью, скамейкой и кассой |
| `npm run test:progression` | Четыре сезона, переход суток, четыре последовательности ремонта, две детали в экспертном аппарате, правила смен, штрафы, запрет повторных выплат; достижимость и однократные награды всех 14 глав |
| `npm run test:e2e` | Полная первая сделка: вступление, обучение, покупка, инструменты, ремонт, сон, доставка, сборка и продажа с сохранением |
| `npm run test:gadgets` | Покупка и полный ремонт геймпада, контакт отвёртки, замена со стола, продажа; модели колонки и наушников |
| `npm run test:advanced` | Экспертный аппарат: две детали, точная пайка, уплотнитель, 12 винтов, калибровка, верная цена и прибыль. Сложный аппарат: прогрев, подъём дисплея и очистка |
| `npm run test:shifts` | Питьё и еда, сюжетная награда, сохранение прокрутки после награды; обе подработки, ошибки, оплата и дневной лимит; подход к другу, громкость музыки и сохранение |
| `npm run test:animation` | Две видимые руки над столом, бутылка достигает рта, еда списывается после действия; диван и возврат на свободный пол; зимняя ночь и сохранение освещения при открытии окна |
| `npm run test:season` | Расширенный дом и район, вечер, маршрут в сквер, поиск запчастей, отдых, история и авторы |
| `npm run test:rework` | Каталоги, высота телефона, корзина на 14 товаров, касса, еда, правильные выходы; ПК, Youpube, монетизация, реклама, рейтинг и сохранение |
| `npm run test:expansion` | Клиентский ремонт и возврат с премией без двойной оплаты; улучшения ПК, обе мини-игры, задания, звуки и выключение звука |
| `npm run test:mobile` | Создание персонажа и обучение, покупки касаниями, корзина на 8 товаров, касса, три заказа подработки с оплатой, управление обеими мини-играми |
| `npm run test:resume` | Продолжение незавершённого обучения, восстановление встречи после перезагрузки и завершение сделки |
| `npm run test:offline` | Архив 0.5 распакован отдельно: одиночный HTML запускается с моделями, шрифтами, музыкой и эффектами, внешних HTTP-загрузок нет |

Все перечисленные проверки завершились успешно; ошибок JavaScript в браузерных сценариях не обнаружено. [Скриншоты](screenshots/0.5).

Автономный HTML проверен через локальный сервер: `file://` блокируется политикой браузера этой облачной среды. Работа на реальном Android, APK и отдельная Windows-сборка не проверялись. Хронометраж полного прохождения кампании не измерялся. Соперники и сюжет работают локально.

Источники музыки и условия распространения перечислены в `web/audio/SOURCES.md`. Эта проверка не подтверждает права на коммерческое распространение музыки, присланной без отдельной лицензии.
