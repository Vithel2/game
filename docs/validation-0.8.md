# Проверки 0.8

Целевые изменения: названия моделей и миграция сохранений, точность шкал прогрева/пайки/калибровки, подсказки инструментов, винты перед герметизацией/закрытием, диагностика на дисплее и итоговый отчёт, съёмка с анимацией, сборка Android.

- `npm run test:release8`: порядок этапов для всех четырёх сложностей, названия, диагностика неисправного и исправленного телефона, границы видимой зоны.
- `npm run test:state`: загрузка старых сохранений.
- `npm run test:progression`: все четыре ремонта, сюжет, смены и сезоны.
- `npm run test:life`: обучение, канал, публикации и игровые ограничения.
- `tests/release7.e2e.mjs`: четыре задания, дом/мебель, покупка сыра, правильная подработка, физическая посылка 013.
- `tests/precision8-mobile.e2e.mjs`: реальные браузерные касания при 390×844, совпадение зелёной зоны с результатом, отпускание пальца после обновления окна.
- `tests/media8.e2e.mjs`: движение свободной руки во время записи, REC, сохранение кадра.
- `tests/release8.e2e.mjs`: промах и попадания в видимую зону прогрева, пайка, 12 винтов до герметизации, закрытие, калибровка, экран диагностики, итоговый отчёт, съёмка с движением и сохранением кадра.

Проверка браузера выполняется в Chromium с программным WebGL. Данные диагностического экрана — внутриигровая имитация характеристик и тестов, реальный сетевой запрос не выполняется. Модели вымышлены, логотипы производителей не используются; это не юридическая гарантия отсутствия претензий.

Android: Cordova 12.0.0 / cordova-android 14.0.1 / JDK 17 / SDK 35 / Gradle 8.13. Тестовый APK успешно собран. `apksigner verify --verbose` подтвердил подпись APK v2; `aapt dump badging` подтвердил пакет com.vithel.perekup, версию 0.8.0/code 800, min SDK 26, target SDK 35. HTML внутри APK побайтно совпадает с окончательным офлайн-архивом после добавления Cordova bridge; JS, модели, шрифты и звук встроены. ZIP-структура APK/архива проверена, секретных файлов подписи внутри нет. Размер APK — 7 810 547 байт. SHA-256: `48079d532a0c74f7a241923346fb3124218e2bb8e64b8e1724dbc3abadd52530`. `npm run test:offline` подтвердил загрузку без внешних запросов. APK с отладочной подписью нужен для тестирования, для RuStore необходим постоянный ключ разработчика. Запуска на физическом Android-устройстве не было.

Полный исторический набор браузерных тестов не прогонялся; старые сценарии ремонта обновлены под новый порядок этапов и подтверждение итогового отчёта.
