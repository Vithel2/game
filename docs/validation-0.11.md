# Проверки 0.11

Исходные проблемы воспроизведены по 13 Android-скриншотам из приложенного архива. Проверки интерфейса выполнены в Chromium с touch-событиями Playwright. Физические Android- и Windows-устройства в среде недоступны; производительность на них не измерялась.

## Новые функции

- `npm run test:release11`: новая публикация не выдаёт просмотры и награды сразу; аудитория, лайки, комментарии, подписчики и доход приходят постепенно. Прогресс продолжается после сериализации сохранения; повторное обновление завершённого ролика не начисляет доход второй раз. Проверены позднее подключение монетизации, миграция названий, iOS/Android/SteamOS и покупка комплектующих без автоматической установки.
- `npm run test:release11-browser`: на экране 360×800 целиком виден интерьер уютного дома; календарь получает анимацию открытия и закрытия. Выполнен переход в отдельную Техноточку, покупка ПК, памяти и наушников, выход к двери магазина и установка памяти дома без повторного списания денег.
- На реальном экране канала опубликован ролик: сначала нулевые просмотры и подписчики, затем пришли первые просмотры. Счётчики обновились в существующем окне без замены DOM; после перезагрузки аудитория сохранилась.
- `tests/house11.e2e.mjs`: на 360×800 все проверяемые углы стартового и максимального дома находятся внутри игровой области. У скрытой гостиной нет плавающих подписей. Подписи на улице компактнее и проходят проверку на резкие скачки при движении камеры.

## Регрессия

- `tests/mobile10.e2e.mjs`: весь ремонт касаниями, пять винтов, отсутствие рук, читаемая основная кнопка. Пройдены обучение, осмотр/покупка с уведомлением, навигация телефона, поворот экрана и ремонт на 320×640, 390×844, 844×390. Подработка Azon: посылка 013 передана, следующий код 042 появляется автоматически.
- `npm run test:release-mobile`: заметка календаря, съёмка трёх кадров, монтаж, публикация и выбор отправки проданного телефона на 390 px. После сокращения плашек отдельно проверены новое обязательное обучение на 320 px, прокрутка диалога и переход в настольную раскладку.
- `npm run test:life`, `npm run test:navigation`, `npm run test:state`, `npm run test:release8`, `npm run test:release9`: ограничения обучения, экономика аудитории, безопасные маршруты, сохранения, имена/диагностика и порядок ремонта.
- `npm run test:offline`: модели, шрифты, музыка и игра запускаются без внешних запросов.

## Дистрибутивы

Собраны APK 0.11.0 / versionCode 1100, Windows x64 EXE с NSIS-установщиком и автономный HTML. Проверены целостность ZIP, подпись APK v2, совпадение встроенного игрового HTML и контрольные суммы. APK использует тот же тестовый сертификат, что версия 0.10, и совместимый ключ сохранения `s-ruk-game-v3` (схема 8). Старые ролики не запускают аудиторию повторно и не теряют ранее начисленные показатели.

APK остаётся тестовой сборкой: для RuStore нужен постоянный ключ разработчика. У Windows-сборки нет коммерческой цифровой подписи, требуется Edge WebView2. Старые выпуски и видео 0.9 сохранены отдельно.
