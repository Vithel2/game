# Проверки 0.10 — мобильный интерфейс

Проверки выполнены в Chromium с эмуляцией телефона и настоящими touch-событиями Playwright. Физический Android-телефон и Windows в этой среде недоступны; производительность на них не измерялась. Приложенные пользователем 16 Android-скриншотов использованы для воспроизведения проблем интерфейса.

## Игровые проверки

- `npm run test:mobile-ui`: полный ремонт на 360×800 от диагностики до итогового отчёта, пять внутренних винтов, снятие/установка детали, соединение разъёмов, закрытие и проверка. Рук нет на всех этапах, движения инструментов и деталей сохранены.
- Экраны 320×640, 390×844 и 844×390: обучение, встреча, обязательный осмотр и покупка, уведомление о попытке покупки без осмотра, навигация приложений, поворот экрана в ремонте. Основные области интерфейса не пересекаются; основные кнопки не меньше 44×44 CSS px. Центры кнопок проверяются через `elementFromPoint`, затем выполняются касания.
- Подработка Azon на 360×800: восемь подписей коробок и подсказка с кодом размещены в своих областях, взята и передана посылка 013, следующий код 042 появляется без нового окна.
- Раскрытая подсказка обучения и прокрутка окна товара сохраняются после осмотра. При переходе из мобильной в настольную раскладку кнопки остаются доступны.
- Новое прохождение на 320 px: сюжет, форма имени/пола/способности при уменьшенной до 420 px высоте, обязательная ходьба и открытие Авиту. Обучение остаётся обязательным.
- `npm run test:release-mobile`: календарь с заметкой, съёмка трёх кадров, монтаж/публикация, выбор отправки проданного телефона на экране 390 px.
- `npm run test:release8-touch`: реальные касания по видимой зелёной зоне прогрева; три успешных попадания, отпускание не закрывает обновлённое окно.
- `npm run test:repair-motion`: на ПК дисплей не дублируется при снятии и установке; отвёртка вращается, наконечник остаётся в винте; рук нет.
- `npm run test:state`, `npm run test:release8`, `npm run test:release9`: совместимость сохранений, порядок ремонта, ограничения винтов и шкалы точности.
- `npm run test:offline`: автономный HTML загружает модели, шрифты и звук без внешних запросов.

## Сборки

- Android: Cordova Android 14.0.1, JDK 17, SDK 35, Gradle 8.13; APK `com.vithel.perekup`, версия 0.10.0, код 1000, Android 8.0+. Проверены ZIP и подпись APK v2. Подпись совпадает с опубликованным APK 0.9; сохранения совместимы. Это тестовая подпись, для RuStore требуется постоянный ключ разработчика.
- Windows: собраны x64 EXE, переносимый ZIP и NSIS-установщик. Проверены структура пакетов и встроенный игровой HTML. Подписи коммерческим сертификатом нет, нужен Edge WebView2.
- Автономный ZIP, APK и Windows содержат одну и ту же проверенную игру, включая новые мобильные стили. Контрольные суммы находятся в `releases/perekup-0.10-checksums.sha256`.

[Кадры новой раскладки](screenshots/0.10/) сняты при проверках. Схема сохранения осталась версии 8; старые выпуски и видео 0.9 сохранены отдельно.
