# Fonts

Nunito variable font, unchanged TTF from Google Fonts:

https://github.com/google/fonts/tree/main/ofl/nunito

Russo One Regular, unchanged TTF from Google Fonts:

https://github.com/google/fonts/tree/main/ofl/russoone

Both use the SIL Open Font License 1.1. Complete license texts are included as `Nunito-OFL.txt` and `RussoOne-OFL.txt`. The files include Cyrillic. They are served locally on the website and embedded directly in the offline HTML. Runtime downloads from Google Fonts are not used.
