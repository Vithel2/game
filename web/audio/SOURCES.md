# Sound sources

Files `coin.ogg`, `jump.ogg`, `land.ogg`, `walking.ogg`, `break.ogg`, and `fall.ogg` come from Kenney's official Starter Kit 3D Platformer repository:

https://github.com/KenneyNL/Starter-Kit-3D-Platformer/tree/3fa8a04b1c01ab23db43123d4ce814a34c3fc7f0/sounds

The repository README explicitly licenses included sound effects under CC0:

https://github.com/KenneyNL/Starter-Kit-3D-Platformer/blob/3fa8a04b1c01ab23db43123d4ce814a34c3fc7f0/README.md#license

CC0: https://creativecommons.org/publicdomain/zero/1.0/

The repository's MIT license is also preserved as `Kenney-LICENSE.md`. Samples are redistributed unchanged. Playback offsets, pitch, and gain are adjusted at runtime for steps, UI, tools, parcels, and rewards. All audio is embedded in the game bundle; no external requests are needed during play.
