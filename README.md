# С рук

Прототип симулятора перекупа и ремонта смартфонов для будущих Android- и ПК-версий.

## Попробовать телефон в браузере

`index.html` — самостоятельная демонстрация приложений телефона, основанная на `art/expansion_01/phone_demo.html`. Работают каталог Azon, корзина, оплата игровыми деньгами, доставка за 1–3 игровых дня и получение деталей. Реальных платежей и заказов нет. Покупка доноров в «Авиту» и ремонт в игровом движке ещё не подключены.

Откройте `index.html` в браузере или разместите репозиторий на GitHub Pages. Для обновления опубликованного прототипа копируйте текущий `art/expansion_01/phone_demo.html` в `index.html`.

### GitHub Pages

В настройках репозитория: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → / (root) → Save**.

После успешного развёртывания ожидаемый адрес: https://vithel2.github.io/game/ . Сохранение исходников в GitHub само по себе не включает Pages.

## Модели и исходники

- [`art/prototypes`](art/prototypes) — первая комната, стол и смартфон.
- [`art/prototypes_v2`](art/prototypes_v2) — обновлённый смартфон с «Авиту».
- [`art/expansion_01`](art/expansion_01) — «Пятак», пункт Azon, инструменты, зарядка, разборный телефон и прототип приложения.
- [`tools`](tools) — скрипты создания моделей и интерфейсов.

В каталогах есть GLB для импорта в движок, исходники Blender, превью, ZIP-архивы и инструкции пересоздания. Это прототипы: сборок APK/Windows пока нет. Названия и оформление рабочих вымышленных сервисов требуют проверки перед релизом.

## Проверки

Все 11 GLB последнего набора повторно импортированы в Blender. В Chromium проверены наличие товара, ограничения количества, списание средств, сроки доставки, одноразовое получение, инвентарь, сохранение после перезагрузки и мобильная ширина интерфейса.
